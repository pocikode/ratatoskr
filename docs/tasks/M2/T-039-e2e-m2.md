## Acceptance criteria
- [ ] Intercept: with Queuing on, a browser navigation blocks until Forward in the UI; an edited header reaches the target;
      Drop answers the browser with 502 and the history row shows dropped; switching to Forwarding releases the rest in order;
      the sidebar badge counts held items.
- [ ] History: the edited pair from Intercept shows the edited marker on both rows; Original/Modified switches both panes.
- [ ] Match & Replace: rule `Request Header / Add / User-Agent: x` → the target sees the header on a proxied request, the
      record is marked edited, and the tester shows the diff (F-MR-1 AC).
- [ ] Replay: ⌘/Ctrl+R from History opens a session; Send shows the response; a deliberately wrong `Content-Length` with
      auto-update off reaches the target byte-for-byte (F-REP-2 AC, checked on the test server); Cancel on a slow target
      shows a cancelled entry; ‹ › navigates entries.
- [ ] Environment: a variable from the selected environment is interpolated into a Replay send; the status bar switch
      changes the value used.
- [ ] Specs run in CI's e2e job and pass three consecutive runs locally (no retries needed).

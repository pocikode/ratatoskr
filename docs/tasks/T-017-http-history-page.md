### Known limitations
- Only the first page is loaded (`first: 1000`, the schema maximum). Paging needs a scroll hook in `TrafficTable`
  (out of this task's paths) — see Out-of-scope #3.
- The §6 rule "pill when the user is scrolled away" is approximated: new rows are buffered while a row is selected,
  inserted live when nothing is selected. The table does not report scroll position yet, so scrolling the top gap alone
  cannot show the pill.
- Column layout is persisted in `localStorage` (`ui-state.ts`) until the backend `ui_state` contract exists; pane sizes are
  not persisted (the layout toggle remounts the split and resets them).
- Bodies are fetched with `limit: 4194304` (the per-call max); a longer body stops at 4 MiB and the viewer title says
  "first 4 MiB". "Open in browser"/Preview mode is not wired: `/preview/{id}` does not exist yet.
- Copy as cURL has the method and URL only: rows do not load `head`/`body`, so headers/body are not included.
- Delete has no confirmation dialog (v1; see the follow-ups). Deleting any selected row clears the whole selection because
  `Selection` has no `remove`.
- The query bar's local syntax check only covers unterminated strings/comments and unbalanced groups; type errors are the
  server's (`BAD_QUERY`), and the dev mock never produces them.
- The row context menu is page-local (roles, arrow keys, Escape, outside click, focus restore) and keyboard-openable
  (Shift+F10) but not the shared `ContextMenu` of T-022.
- No Playwright spec: Playwright is not a dependency yet (T-021).

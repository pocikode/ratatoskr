## Goal
HTTP History page per layout §3.1 using TrafficTable + MessageViewer, a QueryBar with HTTPQL CodeMirror language (highlight, autocomplete via `queryCompletions`, error spans), live rows, context menu v1 (copy URL/cURL, colour, note, filter by host).

## Acceptance criteria
- [ ] Works against mocks and real backend (feature flag in dev).
- [ ] "↓ N new" pill behaviour per §6.
- [ ] Query errors shown inline without clearing the table.
- [ ] Column config persisted via `ui_state` (mock OK until backend exists).

## Plan (implementer, ≤15 lines)
1. Deps (operator-approved 2026-11-18): `@codemirror/{state,view,language,autocomplete,commands}` + `@lezer/highlight`.
2. `lib/query/httpql.ts`: CodeMirror `StreamLanguage` (namespaces, fields, operators, strings, keywords, comments),
   UTF-8 byte ↔ editor offset helpers, a small unterminated string/group check (server `BAD_QUERY` stays authoritative).
3. `lib/query/completions.ts`: completion source that asks `queryCompletions` and maps its byte offsets to the editor.
4. `lib/components/QueryBar/QueryBar.svelte`: single-line CM6, Enter applies, ↑↓ history, error squiggle, leading/trailing snippets.
5. `pages/http-history/http-history.graphql` (rows fragment, requests, request(id) head/body, live subs, completions,
   colour/note/delete mutations) → `bun run codegen`.
6. `pages/http-history/history.svelte.ts`: rows (`$state.raw`), sort, applied query, first page, live merge with the
   "↓ N new" buffer, selection, detail fetch (bodies ≤ 4 MiB, decoded for display).
7. `pages/http-history/`: `columns.ts` (16 columns + sort map), `detail.ts` (base64 → raw message), `ui-state.ts`
   (column config mock persistence), `RowContextMenu.svelte` (bits-ui, items from the command registry).
8. Page commands via `registry.register` (cleanup on destroy): copy URL/cURL, colour, note, filter by host, delete, clear query.
9. Page: QueryBar + SplitPane (table 55 / viewers 45), dev mock flag (`?mock=history` or `history.mock`), row pill, viewers.
10. Tests: tokenizer/offsets, completion mapping, QueryBar apply/error/completions, page against `createMockClient`
    (rows, filter, `BAD_QUERY` keeps rows, live pill, colour/note, config persistence). E2E deferred to T-021.

### Known limitations
- The dev history mock ignores `scopeId` (T-091 finding 6), so with `?mock=history` the selector does not filter rows and
  the scope counter shows the unscoped total. The real backend is correct.
- The scope counter is for the **saved** preset (refreshed on select and after save) because the contract has no
  draft-scope counter (T-091 "Out"); the filter counter is live and shows nothing while the draft does not parse.
- The active scope lives in `HistoryState` only: not persisted to `ui_state`, lost on reload. Only History has a scope
  selector — the other traffic pages are still placeholders.
- Preset lists are plain scroll lists (≤1000 presets) and Delete has no confirmation dialog (as in T-017).
- The filter editor's `QueryBar` has no autocomplete (`queryCompletions` is wired on History only).
- Import uses a hidden file input (no drag & drop); Export downloads `filter-presets.json`.
- Deleting the scope another page has selected falls back to "No scope" on that page's next list load (no subscription).
- No Playwright spec: Playwright is still not a dependency (T-021).

### Follow-ups (proposed)

- Persist the per-page scope selection in `ui_state` once that contract exists (docs/02 §2: "each traffic page has a
  scope selector").
